# Материалы и лицензии

| Материал | Источник и условия |
| --- | --- |
| Код сервера, интерфейса и тестов | Создан ассистентом Codex для этого проекта. Внешний код не копировался. Лицензия распространения проекта пока не выбрана владельцем. |
| Иконки и favicon | Собственные простые SVG-контуры, написанные в проекте. Официальных логотипов вузов нет. |
| Иллюстрации блокнота и экрана входа | Собственные CSS-фигуры и текст, без стоковых изображений и внешних ассетов. |
| Шрифт | Системный стек браузера `-apple-system, BlinkMacSystemFont, Segoe UI, Arial, sans-serif`. Файлы шрифтов не распространяются. |
| Python и стандартная библиотека | Python Software Foundation License; установленный интерпретатор не входит в архив проекта. |
| SQLite | Public domain; доступ через стандартный `sqlite3`, отдельная копия не распространяется. |
| Dockerfile | Ссылается на официальный образ `python:3.12-slim`; образ не собран и не включён в архив. При сборке применяются лицензии его компонентов. |
| Задание конкурса и вложения | Предоставлены пользователем как контекст. Исходные документы, снимок организаторов и их логотипы не включены в приложение и архив. |

Сторонние npm/Python-пакеты, веб-шрифты, внешние фотографии и CDN не используются. Все имена, учебные данные и документы придуманы для демонстрации. Совпадения с реальными людьми случайны.


Обновление анимаций: изучены конкретный fade-in-bottom на Animista и примеры animate/press в документации Motion (ссылки и детали — в `motion-notes.md`). Они использованы только как идеи. Их код, изображения и библиотеки не копировались и не распространяются в проекте. Новые CSS/JavaScript и тесты написаны для Пульса, внешних зависимостей и CDN нет.
