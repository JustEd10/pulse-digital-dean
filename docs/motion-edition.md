# Пульс: выразительные анимации

8 ноября 2026 года. Изменения внесены в Codex моделью GPT-6.1 Sol по прямому запросу капитана: самостоятельно усилить анимации предыдущей версии.

Новые эффекты реализованы собственным CSS без библиотек, CDN и сторонних ассетов. Использован предыдущий архив pulse-project.zip. Сервер и схема БД не менялись.

## Изменения

- Последовательное появление блоков при входе и смене раздела: 440–480 мс с небольшой задержкой между карточками. Отметка дела не перезапускает вход всей страницы.
- Иллюстрация с книгой собирается из отдельных элементов за 750–1100 мс; нет бесконечного фонового движения.
- Вход: появление формы, текста и элементов орбитальной иллюстрации.
- Навигация: отклик иконки и индикатор активного раздела.
- Успеваемость: заполнение полос прогресса при переходе в раздел.
- Диалог: открытие со сдвигом и масштабированием за 320 мс; закрытие за прежние 200 мс, сохранены ограничения фокуса и inert.
- Реальный успешный ответ сохранения отмечается галочкой с кольцевым откликом. Успех не показывается до ответа сервера.
- Кнопки: блик, отклик стрелки и нажатия. Карточки слегка приподнимаются при наведении мыши; hover-эффекты отключены для сенсорного ввода.
- Галочка дела и счётчик уведомлений подтверждают обновление коротким увеличением.
- Декоративное движение отключается при prefers-reduced-motion.

## Проверка

15 серверных тестов со строгой проверкой ресурсов прошли на Python 3.14. Незакрытых SQLite-соединений после тестов не обнаружено. 11 существующих JS-тестов логики диалогов и запросов прошли в Node. Они не проверяют визуальный рендеринг.

В браузере пройдены вход Алисы, переход к успеваемости и заявкам на ширине 360 px, открытие формы, успешная отправка и отображение сохранённой заявки. Проверено закрытие Escape и возврат фокуса. Видимые состояния просмотрены на 360 и 1280 px; ошибок в доступном журнале браузера не найдено. Длительность открытого диалога проверена по вычисленному стилю: 0.32s.

Реальное переключение системной настройки reduced motion и полная матрица браузеров не выполнялись. Поддержка проверена по CSS и существующей изолированной JS-проверкой. Запись видео движения не сделана.

Локальный просмотр новой версии запущен на http://127.0.0.1:8003. Публикация не выполнялась. Созданная при проверке база в архив не входит.
