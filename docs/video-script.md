# Сценарий демонстрации Пульса

План записи длительностью примерно 4 минуты 20 секунд. Само видео не записано. Снимайте работающий сайт с вымышленными данными; не показывайте другие вкладки, уведомления ОС, локальные пути и пароли настоящих сервисов.

| Время | Действие на экране | Что сказать |
| --- | --- | --- |
| 0:00–0:20 | Экран входа и отметка концепта | Пульс объединяет повседневные учебные задачи. Это неофициальный конкурсный прототип с вымышленными данными. |
| 0:20–0:45 | Вход Алисы, главная | Один экран показывает пары, учебные дела и следующий шаг по документу. Это продуктовая гипотеза, интервью пока не проводились. |
| 0:45–1:15 | Расписание: сегодня, изменение аудитории, неделя | Данные занятий и перенос заметны в одном месте. Расписание демонстрационное. |
| 1:15–1:40 | Успеваемость | Разные дисциплины, оценки, зачёты и примерные даты сессии. |
| 1:40–2:30 | Создание справки в двух экземплярах, статус, reload | Заявка сохраняется на сервере. Следующий шаг помогает проверить данные. В демоверсии деканат её не обрабатывает. |
| 2:30–2:50 | Главная, карточка заявки; готовый демообразец | Главная позволяет продолжить сценарий. Образец справки не имеет юридической силы. |
| 2:50–3:15 | Уведомление о деле, отметка дела на главной | Уведомление ведёт к действию, а отметки дел сохраняются. |
| 3:15–3:45 | Телефон или честно обозначенная эмуляция 360 px | Показать переходы нижнего меню и форму заявки. Если используется эмуляция, прямо назвать её эмуляцией, а не физическим телефоном. |
| 3:45–4:10 | Выход, вход Марка, его профиль и заявки | Два студента имеют разные данные. Изоляция реализована сервером и проверена HTTP-тестами. |
| 4:10–4:20 | Финальный экран | Код и документация подготовлены с Codex; точная модель не установлена. Назвать ограничения и ссылку, только если она действительно опубликована капитаном. |

Перед записью капитану нужно проверить внешний URL, звук, курсор, читаемость текста и длительность. Полные демопароли лучше передать в комментарии к конкурсной работе; в видео их показывать необязательно. Не ускоряйте загрузки так, чтобы создавалось ложное представление о фактической скорости.
